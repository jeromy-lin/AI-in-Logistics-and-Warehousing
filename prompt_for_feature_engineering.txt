### 四、建立 Customer-Month Features

請根據 Excel 實際存在的欄位，盡可能建立以下企業物流特徵：

* Monthly Shipment Volume
* Average Package Weight
* Average Package Size
* S60 Ratio
* S90 Ratio
* S120 Ratio
* S150 Ratio
* Delivery City Count
* Remote Delivery Ratio
* Cold Delivery Ratio
* COD Ratio
* Time Slot Ratio
* Redelivery Ratio
* Delivery Failure Ratio

其中：

* 月出貨件數 = 每位客戶每月的包裹筆數
* 平均重量 = 每位客戶每月的平均重量
* 平均尺寸 = 每位客戶每月的平均「長 + 寬 + 高」
* 各尺寸級距比例 = s60、s90、s120、s150 各自占當月出貨件數的比例
* 偏遠配送比例 = 偏遠配送件數 / 月出貨件數
* 低溫配送比例 = 低溫件數 / 月出貨件數
* COD 比例 = COD 件數 / 月出貨件數
* 指定時段比例 = 有指定配送時段件數 / 月出貨件數
* 二次配送比例 = 配送次數 >= 2 的件數 / 月出貨件數
* 配送失敗比例 = 配送失敗件數 / 月出貨件數

如果某一個特徵無法由目前 Excel 的實際欄位建立：

「不要自行捏造資料」
